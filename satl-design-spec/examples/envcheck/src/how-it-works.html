How envcheck works

One file, checked from start to finish.

1

You write the schema

One line per variable the app needs.

PORT: {type: int, default: 8080}
DATABASE_URL: {type: url, required: true}
2

It reads your file

The .env file is read, never changed.

PORT=eighty
3

It checks every variable

Each schema line is one check. All results are collected first.

PORT          type int     "eighty"   fail
DATABASE_URL  required     missing    fail
4

You get every problem at once

✗ DATABASE_URL is required but missing
✗ PORT must be an int, got "eighty"
2 problems
